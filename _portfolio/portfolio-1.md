## Project

Built during a Codanics datathon, this web app analyzes the sentiment of tweets and other text. It fetches tweets through the Twitter API and uses VADER and TextBlob to classify sentiment. The team also explored a [Kaggle dataset](https://www.kaggle.com/competitions/tweet-sentiment-extraction/).

## Outcome and link

The project won first place at the datathon. [Open the app](https://taqihaider-el-tweets-sentiment-analysis-main-pwjsef.streamlit.app/).
