## Project

Built during an [OpenAI Hackathon](https://lablab.ai/event/openai-hackathon/menlo-park-lab/chatty-panda), Chatty Panda answers customer questions using company information and policies. It uses OpenAI models for response generation and embeddings, with Chroma as the vector database.
